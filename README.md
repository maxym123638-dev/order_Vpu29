# 🛒 Telegram Sales Bot — Бот для прийому замовлень

Телеграм бот для прийому замовлень продуктів харчування з повним циклом: каталог → кошик → оформлення → оплата.

## ✨ Функціонал

### Для клієнтів:
- 🛒 Перегляд каталогу товарів по категоріях
- ➕/➖ Вибір кількості кожного товару
- 🧺 Кошик із підрахунком суми
- 📝 Оформлення замовлення (ім'я, телефон, адреса)
- 💳 Отримання реквізитів для оплати
- 🎉 Сповіщення про підтвердження оплати

### Для адміністратора:
- 📲 Миттєві сповіщення про нові замовлення
- ✅ Підтвердження оплати одним натисканням
- 📋 Перегляд всіх замовлень
- 📦 Керування каталогом товарів (додавання нових)
- 💳 Зміна реквізитів оплати командою `/setcard`

## ⚙️ Налаштування

1. **Створіть бота** у [@BotFather](https://t.me/BotFather) та отримайте токен.

2. **Дізнайтесь свій Telegram ID** через [@userinfobot](https://t.me/userinfobot).

3. **Заповніть `.env` файл:**
   ```
   TELEGRAM_TOKEN=ваш_токен_від_BotFather
   ADMIN_ID=ваш_telegram_id
   PAYMENT_CARD=5375 4141 XXXX XXXX
   PAYMENT_NAME=Ваше Ім'я Прізвище
   PAYMENT_BANK=Monobank
   ```

4. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Запустіть бота:**
   ```bash
   python main.py
   ```

## 📦 Керування товарами

Товари зберігаються у файлі `products.json`. Ви можете:
- Редагувати файл вручну
- Додавати через адмін-панель у боті (кнопка "⚙️ Адмін-панель")

### Формат додавання товару через бот:
```
Назва | Ціна | Одиниця | Категорія
```
Приклад: `Олія оливкова | 120 | л | Олія та жири`

## 💳 Зміна реквізитів оплати

```
/setcard 5375 4141 1234 5678 Іван Петренко Monobank
```

## 📁 Структура файлів

```
telegram_bot_sales/
├── main.py          # Головний файл бота
├── products.json    # Каталог товарів
├── orders.json      # Збережені замовлення (створюється автоматично)
├── .env             # Налаштування (токен, реквізити)
├── .env.example     # Шаблон налаштувань
└── requirements.txt # Залежності
```

## 🔧 Адмін-команди

| Команда | Опис |
|---------|------|
| `/admin` | Відкрити адмін-панель |
| `/orders` | Переглянути останні замовлення |
| `/products` | Список всіх товарів |
| `/setcard <реквізити>` | Змінити реквізити картки |
